# NetScope

**NetScope** — инструмент для визуализации и изучения IT-инфраструктуры. Позволяет подключаться к удалённым Linux-серверам по SSH, отображать инфраструктурные компоненты и наглядно представлять связи между ними.

Вместо работы исключительно через терминал NetScope предоставляет интерактивную карту инфраструктуры, на которой можно размещать серверы, Docker-контейнеры и сервисы, а также отображать отношения между ними.

## Возможности

- **Визуализация инфраструктуры** — интерактивная карта серверов и инфраструктурных компонентов.
- **SSH-подключение** — подключение к удалённым Linux-серверам.
- **Docker-интеграция** — отображение Docker-контейнеров.
- **Топология инфраструктуры** — визуальное представление связей между серверами, контейнерами и сервисами.
- **Управление элементами** — добавление и организация компонентов на интерактивной карте.

## Цель проекта

Цель NetScope — упростить понимание и исследование серверной инфраструктуры с помощью визуального представления её архитектуры.

Проект объединяет разработку веб-приложений, системное администрирование и сетевые технологии в одном инструменте.

## Статус проекта

NetScope находится в разработке. Функциональность и архитектура проекта постепенно расширяются.
